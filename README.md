# Flutter E-commerce

Full-featured Flutter e-commerce app with product grid, cart management, and checkout flow using Riverpod state management.

**Stack:** Flutter | **Complexity:** moderate
**Tags:** `flutter`, `mobile`, `ecommerce`, `riverpod`, `gorouter`, `cart`, `checkout`, `material3`

## Quick Start

```bash
flutter pub get
flutter run
```

## Claude Code
